## Overview

**AI Automation Script Generator** is a full-stack web application that lets QA engineers and testers enter test steps in plain English, select an automation framework, and receive complete, executable automation scripts generated by AI.

The backend engineers an optimized prompt — incorporating framework, language, browser, design pattern, and optional requirements — and sends it to one of three AI providers (Groq, OpenAI, or Gemini). The generated code is displayed in a Monaco Editor with syntax highlighting, ready to copy or download.

## Quick Start

### Prerequisites

- **Python 3.11+** and **Node.js 18+** installed

### 1. Backend

```bash
cd backend

# Create virtual environment (recommended)
python -m venv venv
venv\Scripts\activate       # Windows
source venv/bin/activate    # macOS / Linux

# Install dependencies
pip install -r requirements.txt

# Configure environment
cp .env.example .env

# Add at least one AI provider API key in .env
# GROQ_API_KEY=gsk_...
# OPENAI_API_KEY=sk-...
# GEMINI_API_KEY=...

# Start the server
python -m uvicorn app.main:app --reload --port 8000
```

Backend runs at **http://localhost:8000**  
Swagger docs at **http://localhost:8000/docs**

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

App opens at **http://localhost:5173**

### 3. Docker (PostgreSQL + Full Stack)

```bash
docker compose -f docker/docker-compose.yml up --build
```

Starts three containers: PostgreSQL 16, backend, and frontend.

### 4. Vercel (Serverless Deployment)

The project is configured for one-command deployment to Vercel. The root `vercel.json` handles both the Python backend (via serverless function at `api/index.py`) and the React frontend (served as static files from FastAPI).

```bash
vercel --prod
```

**How it works**: Vercel detects `api/index.py` as a Python serverless function. The build command (`cd frontend && npm install --include=dev && npm run build`) produces the static `frontend/dist/` directory. At runtime, FastAPI serves API routes normally and falls back to serving `index.html` for all non-API paths, enabling React Router client-side navigation.

## Features

### AI Script Generator

The core feature — enter natural language test steps and get production-ready code.

- **Large text area** with example placeholder showing test steps
- Framework, Browser, and Design Pattern dropdowns
- **Advanced Options** panel with collapsible controls:
  - Temperature (0–2), Top P (0–1), Max Tokens (100–16,000)
  - Custom system prompt and custom prompt template with `{test_steps}`, `{framework}`, `{language}`, `{browser}`, `{design_pattern}` variables
- **8 boolean toggles**: Assertions, Comments, Explicit Waits, Error Handling, Logging, Screenshots, Retry Logic, Generate Test Data
- Monaco Editor output with syntax highlighting (language auto-detected)
- AI typing indicator with blinking cursor animation
- Action toolbar: **Copy**, **Download** (proper file extension), **Favorite**, **Fullscreen**

### Multi-Framework & Multi-Provider

**Frameworks**

| Framework              | Language   | File Extension |
| ---------------------- | ---------- | -------------- |
| Selenium Java          | Java       | `.java`        |
| Selenium Python        | Python     | `.py`          |
| Playwright JavaScript  | JavaScript | `.js`          |
| Playwright TypeScript  | TypeScript | `.ts`          |
| Cypress                | JavaScript | `.js`          |
| Robot Framework        | Robot      | `.robot`       |

**Browsers:** Chrome, Firefox, Edge, Safari

**Design Patterns:** Page Object Model (POM), Screenplay, Keyword Driven, Hybrid

**AI Providers**

Users can switch between Groq (Llama 3.3), OpenAI (GPT-4o), and Google Gemini (2.0 Flash). Each user can bring their own API key per provider — keys are encrypted with Fernet before storage. Falls back to environment-level keys if no user key set.

### Dashboard

- **3 stat cards**: Total Scripts, Today's Scripts, Favorite Scripts
- **Framework Usage Bar Chart** (Recharts) showing distribution across frameworks
- **Language Usage Donut Chart** (Recharts) showing language breakdown
- **Recent Activity** feed of last 5 generated scripts
- Quick-action button to jump to the Generator page

### History & Export

- Paginated history with full-text search
- Filters: Framework, Language, custom date range (From / To)
- **Favorite / Unfavorite** toggle on any script
- **Export** all history as CSV or Excel (.xlsx) — streaming download
- **Saved Scripts** page — dedicated view of all favorited scripts

### Prompt Library

**9 pre-built system prompts** crafted with the RICEPOT framework (Role, Instructions, Context, Examples, Parameters, Output, Tone). Each prompt contains 9–18 specific test case definitions with unique TC-IDs.

| Prompt        | Category      | Test Cases | Scope                                                                                   |
| ------------- | ------------- | ---------- | --------------------------------------------------------------------------------------- |
| Login Test    | login         | 9          | Valid/invalid credentials, account lockout, SQL injection, XSS, Remember Me, WCAG tab order |
| Registration  | registration  | 12         | Multi-step form, password policy, email uniqueness check, OTP verification, terms acceptance |
| Checkout      | checkout      | 15         | Guest + authenticated checkout, promo codes, shipping methods, tax calculation, 3D Secure |
| Payment       | payment       | 14         | Credit/debit cards, digital wallets, ACH transfers, full/partial refunds, idempotency      |
| Search        | search        | 15         | Autocomplete, faceted filters, price range, pagination, sorting, spellcheck suggestions     |
| Cart          | cart          | 16         | Add/remove/update items, stock limits, save-for-later, cart totals, cross-tab persistence   |
| CRUD          | crud          | 16         | Create, Read, Update, Delete — optimistic updates, concurrency conflicts, bulk operations   |
| API Login     | api           | 18         | JWT lifecycle, refresh rotation, rate limiting, RBAC, security headers, SQL injection in API |
| File Upload   | file_upload   | 18         | Single/multi-file, drag-and-drop, chunked uploads, virus scan, network recovery, file preview |

**Custom prompts** — create, edit, and delete your own. System prompts are protected.

### Script Templates

**6 domain-specific templates** with complete Playwright TypeScript code, Page Object Models, and 5 test cases each:

| Template         | Domain      | Key Flows                                                                         |
| ---------------- | ----------- | --------------------------------------------------------------------------------- |
| E-Commerce       | ecommerce   | Product search & filter, cart quantity update, checkout, payment, order confirmation |
| Banking          | banking     | 2FA login, account summary, fund transfer, insufficient balance, bill pay scheduling |
| Healthcare       | healthcare  | Patient registration with insurance, appointment booking, medical records access, prescription refill |
| CRM              | crm         | Lead creation & conversion, deal progression, activity logging, pipeline report export |
| Travel           | travel      | Flight search & booking, hotel booking, itinerary modification, online check-in    |
| E-Learning       | education   | Browse catalog, enroll with payment, module completion, quiz taking, certificate download |

Each template displays its domain badge, test case count, line count, and code preview. Open a modal to view the full code and copy it.

### Authentication & Security

| Feature                  | Implementation                                                              |
| ------------------------ | --------------------------------------------------------------------------- |
| **Signup**               | Email, username, password (min 6 chars), optional full name                 |
| **Login**                | JWT access token (60 min expiry), auto-redirect to dashboard                |
| **Forgot Password**      | Email-based reset with time-limited token (1 hour expiry)                   |
| **Reset Password**       | Token validation, new password with same strength requirements               |
| **Profile**              | Update full name and username                                              |
| **Rate Limiting**        | Per-IP sliding window — returns HTTP 429 when exceeded (configurable limit)  |
| **API Key Encryption**   | Fernet symmetric encryption for user-provided provider keys                  |
| **Prompt Sanitization**  | Strips injection patterns: `ignore all previous instructions`, `system:override`, `<\|endoftext\|>`, `[INST]` |
| **CSRF Protection**      | JWT Bearer tokens in Authorization header                                   |
| **CORS**                 | Configurable allowed origins                                                |
| **Toast Notifications**  | Success, error, warning, info — auto-dismiss after 4 seconds, rendered globally |

### Admin Panel

*Requires admin role.* Accessible from the sidebar for admin users.

- **Platform Stats**: Total users, total scripts, total prompts, active users today
- **User Management**: Full user list with email, username, role badge, creation date
- **Daily Usage Analytics**: Script generation counts per day (last 7 to 365 days)
- **Framework Distribution**: Breakdown by framework
- **API Consumption**: Provider-level usage statistics
- **Audit Logs**: Event-type, user, timestamp, and IP address

### UI/UX

- Professional SaaS design with gradient accents and glass-morphism effects
- **Dark mode / Light mode** with persisted preference (localStorage)
- Responsive layout — mobile-friendly navigation
- Fixed left sidebar (64px) with icon-based navigation
- Sticky header with search bar and notification bell
- **Skeleton loading** states on every data-fetching view
- **Framer Motion** animations for page transitions and cards
- AI typing cursor animation during script generation
- Animated toast notifications with type-specific colors and icons

## API Reference

> **Base URL:** `http://localhost:8000/api`  
> All protected endpoints require `Authorization: Bearer <token>` header.  
> Interactive docs at **http://localhost:8000/docs**

### Authentication — `/api/auth`

| Method | Endpoint               | Auth   | Status  | Description                                     |
| ------ | ---------------------- | ------ | ------- | ----------------------------------------------- |
| POST   | `/api/auth/signup`     | Public | 201     | Create account. Returns JWT + user object.       |
| POST   | `/api/auth/login`      | Public | 200     | Authenticate. Returns JWT + user object.         |
| POST   | `/api/auth/forgot-password` | Public | 200 | Send password reset link via Resend email.        |
| POST   | `/api/auth/reset-password`  | Public | 200 | Reset password with token from email.            |

### System — `/api`

| Method | Endpoint            | Auth   | Description                          |
| ------ | ------------------- | ------ | ------------------------------------ |
| GET    | `/api/health`       | Public | Health check — returns `{"status":"ok","version":"1.0.0"}` |

### Users — `/api/users`

| Method | Endpoint            | Auth   | Description                          |
| ------ | ------------------- | ------ | ------------------------------------ |
| GET    | `/api/users/me`     | Bearer | Get current user profile.            |
| PUT    | `/api/users/me`     | Bearer | Update full_name and/or username.    |

### Scripts — `/api/scripts`

| Method | Endpoint                          | Auth   | Status | Description                                                      |
| ------ | --------------------------------- | ------ | ------ | ---------------------------------------------------------------- |
| POST   | `/api/scripts/generate`           | Bearer | 201    | Generate automation script via AI.                                |
| GET    | `/api/scripts/stats/dashboard`    | Bearer | 200    | Dashboard stats — totals, framework/lang usage, recent activity.   |
| GET    | `/api/scripts`                    | Bearer | 200    | Paginated history. Query: `page`, `page_size`, `search`, `framework`, `language`, `date_from`, `date_to`, `favorite_only`. |
| GET    | `/api/scripts/export/csv`         | Bearer | 200    | Export all scripts as CSV (streaming download).                    |
| GET    | `/api/scripts/export/excel`       | Bearer | 200    | Export all scripts as Excel .xlsx (openpyxl, streaming).           |
| GET    | `/api/scripts/{script_id}`        | Bearer | 200    | Get a single script by ID.                                       |
| DELETE | `/api/scripts/{script_id}`        | Bearer | 200    | Delete a script (owner only).                                     |
| PATCH  | `/api/scripts/{script_id}/favorite` | Bearer | 200  | Toggle favorite status on a script.                               |

### Prompts — `/api/prompts`

| Method | Endpoint                      | Auth   | Status | Description                                       |
| ------ | ----------------------------- | ------ | ------ | ------------------------------------------------- |
| GET    | `/api/prompts`                | Bearer | 200    | List all system prompts + user's custom prompts.   |
| POST   | `/api/prompts`                | Bearer | 201    | Create a new custom prompt.                        |
| PUT    | `/api/prompts/{prompt_id}`    | Bearer | 200    | Update a prompt (owner or system prompt).          |
| DELETE | `/api/prompts/{prompt_id}`    | Bearer | 200    | Delete a prompt (custom only, not system).          |

### Templates — `/api/templates`

| Method | Endpoint                          | Auth   | Status | Description                                    |
| ------ | --------------------------------- | ------ | ------ | ---------------------------------------------- |
| GET    | `/api/templates`                  | Bearer | 200    | List all system templates + user's templates.   |
| POST   | `/api/templates`                  | Bearer | 201    | Create a new template.                          |
| PUT    | `/api/templates/{template_id}`    | Bearer | 200    | Update a template.                              |
| DELETE | `/api/templates/{template_id}`    | Bearer | 200    | Delete a template.                              |

### Settings — `/api/settings`

| Method | Endpoint                           | Auth   | Description                                   |
| ------ | ---------------------------------- | ------ | --------------------------------------------- |
| GET    | `/api/settings/ai`                 | Bearer | Get default provider, temperature, top_p, max_tokens, configured providers. |
| POST   | `/api/settings/api-keys`           | Bearer | Save/update encrypted API key for a provider.  |
| DELETE | `/api/settings/api-keys/{provider}`| Bearer | Remove API key for a provider.                |

### Admin — `/api/admin` *(admin role required)*

| Method | Endpoint                             | Auth  | Description                                        |
| ------ | ------------------------------------ | ----- | -------------------------------------------------- |
| GET    | `/api/admin/stats`                   | Admin | Platform stats — total users, scripts, prompts.     |
| GET    | `/api/admin/users`                   | Admin | List all registered users.                          |
| GET    | `/api/admin/analytics/usage`         | Admin | Daily script generation counts (up to 365 days).     |
| GET    | `/api/admin/analytics/frameworks`    | Admin | Framework distribution counts.                      |
| GET    | `/api/admin/analytics/api-consumption` | Admin | API provider usage breakdown.                     |
